# 🎬 Movies Recommendation System

A web-based **Movie Recommendation System** built using **Content-Based Filtering**. This app suggests movies similar to the one you like, based on content such as genres, keywords, cast, and crew.

📊 Example
Enter a movie like Inception, and you'll get a list of similar movies like Interstellar, The Prestige, etc.

---

## 🔍 Overview

This project uses **Content-Based Filtering** to recommend movies. The model finds similarities between movies using features like:

- Genres
- Overview
- Keywords
- Cast & Crew

It uses cosine similarity to recommend top 5 similar movies based on a given input movie.

---

## 💡 Features

- Recommend similar movies based on content.
- Clean and simple interface.
- Built with Flask and deployed using Render.
- Lightweight and easy to use.
